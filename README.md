# Плагины x09 для gpupdate

Набор плагинов для системы групповых политик gpupdate (GPOA) на ОС Альт, позволяющий централизованно управлять различными аспектами конфигурации клиентских машин через групповые политики домена.

## Состав

### Межсетевой экран (iptables)

Плагин `x09_firewall` управляет правилами межсетевого экрана (iptables) на клиентских машинах.

**Возможности:**
- Централизованное управление правилами iptables через ADMX-шаблоны
- Поддержка TCP/UDP протоколов, входящих и исходящих направлений
- Действия: Allow (разрешить), Deny (запретить), Reject (отклонить с уведомлением)
- Фильтрация по IP-адресам источника и назначения (с поддержкой CIDR)
- Поддержка одиночных портов, диапазонов (53-153) и списков (22,80,443)

**Формат правила:**
```
Action=Allow|Deny|Reject;Direction=In|Out;Protocol=TCP|UDP;Port=порт;Source=IP;Destination=IP
```

**Примеры:**
```
Action=Allow;Direction=In;Protocol=TCP;Port=80;Source=10.0.0.0/24
Action=Deny;Direction=Out;Protocol=UDP;Port=53;Destination=8.8.8.8
Action=Allow;Direction=In;Protocol=TCP;Port=22,80,443
```

**Ограничения:**
- Поддерживается только классический iptables (IPv4), цепочки INPUT/OUTPUT
- IPv6 (ip6tables) и nftables не поддерживаются
- Порт применяется как порт назначения (--dport) для обоих направлений

### Управление ролями (libnss-role)

Плагин `x09_nssrole` управляет файлами ролей в `/etc/role.d/`, определяющими вхождение групп в группы через NSS-модуль libnss-role.

**Возможности:**
- Централизованное управление ролями и привилегиями пользователей
- Определение вхождения групп в группы (рекурсивное применение)
- Поддержка доменных групп (в т.ч. с кириллическими именами)
- Настраиваемое имя файла ролей (по умолчанию custom-roles.role)

**Формат определения роли:**
```
<группа>:<группа>[,<группа>]*
```

где слева от двоеточия — имя роли (группа, которая будет входить в другие группы), справа — список групп через запятую, в которые входит данная роль.

**Примеры:**
```
users: cdwriter, cdrom, audio, video, camera, floppy
localadmins: wheel
администраторы домена:localadmins
WIN\администраторы домена:localadmins
powerusers: remote, users
```

**Допустимые символы в именах групп:**
- латиница, кириллица, цифры
- символы: `\` `-` `_` (обратный слэш, дефис, подчёркивание)
- пробелы

**Стратегия применения:**
Файл `/etc/role.d/<filename>` полностью перезаписывается содержимым из политики при каждом запуске gpupdate.

## Установка

### ADMX шаблоны (на контроллере домена)

Все ADMX шаблоны устанавливаются одним пакетом `admx-x09`:

```bash
# Установка пакета
apt-get install admx-x09

# Или вручную:
cp admx/*.admx /usr/share/PolicyDefinitions/
cp admx/ru-RU/*.adml /usr/share/PolicyDefinitions/ru-RU/
cp admx/en-US/*.adml /usr/share/PolicyDefinitions/en-US/

# Загрузка в SysVol
samba-tool gpo admxload -UAdministrator
```

В редакторе групповых политик шаблоны появятся в категории **"Сторонние шаблоны"** с подкатегориями:
- Межсетевой экран (iptables)
- Управление ролями (libnss-role)

### Плагины (на клиентских машинах)

Плагины устанавливаются отдельными пакетами по выбору:

**Плагин межсетевого экрана:**
```bash
apt-get install gpupdate-firewall-plugin
```

Устанавливает:
- `/usr/lib/gpoa/plugins/x09_firewall.py`
- `/usr/lib/gpoa/plugins/locale/{ru_RU,en_US}/LC_MESSAGES/x09_firewall.mo`

**Плагин управления ролями:**
```bash
apt-get install gpupdate-nssrole-plugin
```

Устанавливает:
- `/usr/lib/gpoa/plugins/x09_nssrole.py`
- `/usr/lib/gpoa/plugins/locale/{ru_RU,en_US}/LC_MESSAGES/x09_nssrole.mo`

### Требования

**На контроллере домена:**
- Samba 4 (DC)
- Пакет `admx-x09`

**На клиентских машинах:**
- `gpoa-lib` (механизм плагинов gpupdate)
- Для плагина firewall: `iptables`, `iptables-services`
- Для плагина nssrole: `libnss-role`

## Применение политик

После создания и настройки GPO на контроллере домена, запустите на клиенте:

```bash
gpupdate -t COMPUTER -s -l 0
```

Плагины запускаются в машинном контексте (с правами root) при каждом обновлении политик.

## Локализация

Все плагины поддерживают русский и английский языки через GNU gettext. Отображаемый язык определяется локалью системы.

```
│   ├── x09-LibnssRole.admx  # Шаблон для управления ролями
│   ├── ru-RU/               # Русские переводы
│   └── en-US/               # Английские переводы
├── iptables/                # Плагин межсетевого экрана
│   ├── plugin/x09_firewall.py
│   ├── locale/
│   └── tests/
└── libnssrole/              # Плагин управления ролями
    ├── plugin/x09_nssrole.py
    ├── locale/
    ├── po/
    └── tests/
```
